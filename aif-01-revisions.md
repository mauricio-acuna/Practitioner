## Para que sirve esta pagina

AWS actualiza periodicamente las guias de examen. Esta pagina resume cambios publicados para AIF-C01 y ayuda a estudiar con el temario correcto.

## Historial de cambios

| Version | Fecha de publicacion |
|---|---|
| 1.0 | 26 de marzo de 2026 |
| 1.1 | 30 de abril de 2026 |

## Cambios importantes en objetivos

La version 1.1 amplio el foco en varias areas:

- Agentic AI.
- Tipos de inferencia: asincrona y serverless.
- Knowledge bases y agentic AI como casos reales.
- Diferencia entre modelos tradicionales ML y modelos fundacionales.
- Precio basado en tokens.
- Context engineering.
- Conceptos multiagente y MCP.
- Distillation en personalizacion de FMs.
- Human-in-the-loop evaluation.
- LLM-as-a-judge.
- Bedrock Prompt Management.
- Metricas de alineacion con objetivos de negocio.
- Seguridad de agentes con AgentCore Identity y politicas.
- Prevencion de fuga de datos.
- Validacion de salida.
- Auditoria de interacciones IA.
- Deteccion de alucinaciones y grounding.

## Objetivos agregados

- Identificar cuando usar modelos tradicionales ML frente a modelos fundacionales.
- Describir precio basado en tokens y su efecto en costo/rendimiento.
- Describir context engineering.
- Definir conceptos de agentic AI, patrones multiagente, MCP, memoria, herramientas y orquestacion.
- Describir estrategias de versionado y gestion de prompts con Amazon Bedrock Prompt Management.
- Identificar metricas de negocio como tasa de finalizacion de tarea, satisfaccion de usuario y costo por interaccion.
- Describir metodos de deteccion de alucinaciones y grounding como RAG, validacion de salida y confidence scoring.

## Cambios en servicios dentro del alcance

Servicios agregados a la lista dentro del alcance:

- Amazon Aurora.
- Amazon Bedrock AgentCore.
- Kiro.
- Strands Agents.
- Amazon Q.
- Amazon SageMaker JumpStart.
- AWS Transform.

Servicio eliminado de la lista dentro del alcance:

- Amazon MemoryDB.

## Cambios en servicios fuera del alcance

Servicios eliminados de la lista fuera del alcance:

- AWS DeepComposer.
- Amazon FinSpace.
- Amazon Honeycode.
- AWS IAM Identity Center.
- AWS Marketplace.
- AWS Organizations.
- Amazon WorkDocs.

## Impacto para estudiar

Prioriza especialmente:

- Dominar RAG frente a fine-tuning.
- Entender agentes, herramientas, memoria, MCP y AgentCore.
- Relacionar GenAI con seguridad: prompt injection, data leakage, validacion de salida y logs.
- Conocer servicios nuevos dentro del alcance.
- Practicar preguntas con metricas de negocio, no solo metricas tecnicas.

## Regla practica

Si tus apuntes no incluyen Agentic AI, MCP, Amazon Bedrock AgentCore, Kiro, Strands Agents, Amazon Q, token pricing, context engineering y LLM-as-a-judge, estan incompletos para la version 1.1.
