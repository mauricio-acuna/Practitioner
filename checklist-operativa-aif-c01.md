# Checklist operativa para reservar y rendir AIF-C01

Version: 2026-05-28  
Uso: lista de control para no perder tiempo ni cometer errores administrativos antes de rendir AWS Certified AI Practitioner AIF-C01.

## Fuentes oficiales base

- Politicas antes del examen: https://aws.amazon.com/certification/policies/before-testing/
- Pearson VUE para AWS: https://www.pearsonvue.com/us/en/aws.html
- Localizador de centros Pearson VUE para AWS: https://wsr.pearsonvue.com/testtaker/find/testcenter/AWS?locale=en_US
- Beneficios AWS Certified: https://aws.amazon.com/certification/benefits/

## Decision 1: idioma del examen

| Opcion | Cuando conviene | Riesgo | Accion |
|---|---|---|---|
| Ingles + `ESL +30 MINUTES` | Lees ingles tecnico razonablemente bien y quieres 30 minutos extra | Puede cansar mas si tu lectura en ingles es lenta | Pedir accommodation antes de reservar |
| Castellano | Prefieres comprender rapido y reducir carga mental | Puede haber terminos traducidos raros | Practicar con terminos ingleses clave |
| Castellano con apoyo del toggle a ingles | Quieres leer en castellano, pero consultar terminos en ingles si dudas | Debes acostumbrarte a la interfaz | Probar AWS Exam Demo si esta disponible |

AWS indica que los examenes localizados permiten ver las preguntas en ingles durante el examen mediante una funcion de cambio de idioma. Aun asi, conviene verificarlo en la demo y en la confirmacion de Pearson VUE antes de rendir.

## Decision 2: pedir o no `ESL +30`

Pidelo si se cumplen estas condiciones:

- No eres hablante nativo de ingles.
- Vas a rendir el examen en ingles.
- Quieres disponer de 30 minutos adicionales.
- Todavia no reservaste el examen.

No lo dejes para despues de reservar. AWS dice que debe solicitarse antes de registrarte al examen.

Pasos:

1. Entra en `aws.training/Certification`.
2. Ve a tu cuenta.
3. Abre `Request Exam Accommodations`.
4. Selecciona `Request Accommodation`.
5. En tipo de accommodation, elige `ESL +30 MINUTES`.
6. Crea la solicitud.
7. Espera a que figure aprobado antes de reservar.

## Decision 3: centro fisico u online OnVUE

| Modalidad | Recomendada si... | Evitala si... |
|---|---|---|
| Centro fisico Pearson VUE | Quieres entorno controlado, menos problemas tecnicos y tienes un centro cerca | El traslado te genera mucho estres |
| Online OnVUE | Necesitas flexibilidad horaria y tienes equipo/red/espacio adecuados | Tu conexion, camara, microfono o espacio no son fiables |

Para un primer examen, si tienes un centro fisico razonable, suele ser la opcion mas tranquila.

## Checklist antes de reservar

- [ ] Tengo cuenta AWS Certification activa.
- [ ] Mi nombre legal coincide exactamente con mi documento de identidad.
- [ ] Se que idioma voy a elegir.
- [ ] Si aplica, pedi `ESL +30 MINUTES`.
- [ ] Si aplica, el accommodation ya aparece aprobado.
- [ ] Revise precio actual, impuestos y metodo de pago/voucher.
- [ ] Elegi si rendire en centro fisico o por OnVUE.
- [ ] Si es centro fisico, busque centros con el localizador Pearson VUE oficial.
- [ ] Si es OnVUE, revise requisitos de equipo, camara, microfono, red y espacio.
- [ ] Tengo 2 o 3 fechas posibles.
- [ ] No tengo viajes, guardias ni reuniones criticas ese dia.

## Como buscar centros fisicos en Espana

No uses una lista estatica como verdad final. Usa siempre el localizador oficial de Pearson VUE para el programa AWS.

Flujo:

1. Abre https://www.pearsonvue.com/us/en/aws.html
2. Entra en `Find a test center`.
3. Busca por ciudad o codigo postal.
4. Comprueba que el programa sea `Amazon Web Services (AWS)`.
5. Revisa fechas disponibles.
6. Antes de pagar, verifica direccion, hora y politicas.

Centros/candidatos a buscar por ciudad:

| Zona | Centros o referencias para buscar |
|---|---|
| Madrid centro | Dignitae Formacion, Gadesoft, Skillsoft / Global Knowledge |
| Madrid norte | FlexTech, Tres Cantos |
| Barcelona | Escola Espai |
| Valencia | Nextraining |
| Sevilla | Core Networks Sevilla |

Importante: que un centro publique que es Pearson VUE no garantiza que tenga disponibilidad actual para AWS en la fecha que quieres. La confirmacion final siempre es Pearson VUE.

## Checklist al reservar

- [ ] Entro desde mi cuenta AWS Certification, no desde una pagina suelta.
- [ ] Selecciono `AWS Certified AI Practitioner`.
- [ ] Selecciono Pearson VUE.
- [ ] Confirmo idioma.
- [ ] Confirmo accommodation si aplica.
- [ ] Confirmo modalidad: centro fisico u online.
- [ ] Confirmo fecha y hora local.
- [ ] Confirmo direccion exacta del centro si aplica.
- [ ] Reviso politicas de reprogramacion.
- [ ] Guardo correo de confirmacion.
- [ ] Agrego recordatorios a calendario: 7 dias, 48 horas y 24 horas antes.

## Checklist 7 dias antes

- [ ] Hice al menos un simulador completo.
- [ ] Revise errores por dominio.
- [ ] Repase `RAG vs fine-tuning vs prompt engineering`.
- [ ] Repase seguridad: IAM, KMS, Macie, CloudTrail, CloudWatch, Config, Artifact, Audit Manager.
- [ ] Repase IA responsable: bias, fairness, Clarify, Model Cards, Guardrails.
- [ ] Revise la ruta al centro o requisitos OnVUE.
- [ ] Tengo documentos de identidad vigentes.

## Checklist 48 horas antes

- [ ] Segundo simulador o repaso cronometrado.
- [ ] Confirmo hora del examen.
- [ ] Confirmo direccion o enlace OnVUE.
- [ ] Releo correo de Pearson VUE completo.
- [ ] Reviso politica de objetos permitidos.
- [ ] Si voy a centro fisico, planeo transporte con margen.
- [ ] Si voy online, hago test del sistema.

## Checklist 24 horas antes

- [ ] No intento aprender temas nuevos grandes.
- [ ] Repaso tarjetas de memoria.
- [ ] Preparo documento de identidad.
- [ ] Duermo razonablemente.
- [ ] Evito mover la cita salvo emergencia; dentro de 24 horas puede no ser posible cancelar/reprogramar.

## Dia del examen en centro fisico

- [ ] Llego con margen.
- [ ] Llevo documento de identidad original y vigente.
- [ ] Llevo segundo documento solo si la confirmacion lo pide.
- [ ] No llevo apuntes a la sala.
- [ ] Guardo movil/reloj/dispositivos segun instrucciones.
- [ ] Leo el tutorial inicial.
- [ ] Marco preguntas dudosas y sigo.
- [ ] No dejo preguntas en blanco.

## Dia del examen OnVUE

- [ ] Ordenador cargado y conectado.
- [ ] Webcam y microfono probados.
- [ ] Mesa limpia.
- [ ] Habitacion sin interrupciones.
- [ ] Documento de identidad listo.
- [ ] Telefono disponible solo para check-in si el flujo lo requiere.
- [ ] Sin auriculares, papeles, pantallas extra ni dispositivos no permitidos.
- [ ] Me conecto con margen.

AWS indica que en examenes online hay comunicacion obligatoria con proctor. Tambien publica disponibilidad de proctoring por idioma; revisa la pagina oficial porque los horarios pueden no coincidir comodamente con Espana.

## Estrategia durante el examen

Sin `ESL +30`, tienes 90 minutos:

- Primera pasada: 55 minutos.
- Marcadas: 20 minutos.
- Respuesta multiple/orden: 10 minutos.
- Revision final: 5 minutos.

Con `ESL +30`, deberias tener 120 minutos:

- Primera pasada: 70 minutos.
- Marcadas: 30 minutos.
- Respuesta multiple/orden: 15 minutos.
- Revision final: 5 minutos.

Reglas:

- Si dudas mas de 90 segundos, marca y avanza.
- En "elige dos", no marques una sola.
- Si la pregunta pide seguridad, no elijas solo prompt: busca IAM, logs, cifrado, validacion o guardrails.
- Si la pregunta pide datos internos actualizados, piensa RAG.
- Si la pregunta pide estilo/tarea con ejemplos, piensa fine-tuning.
- Si la pregunta pide formato, piensa prompt engineering.

## Proximos pasos segun situacion

### Si todavia no reservaste

1. Decide idioma.
2. Pide `ESL +30` si corresponde.
3. Busca centros o valida OnVUE.
4. Haz simulador completo.
5. Reserva cuando tengas 80-85% sostenido.

### Si ya reservaste

1. No cambies todo el plan.
2. Revisa dominios flojos.
3. Haz tarjetas a diario.
4. Haz un simulador 48-72 horas antes.
5. Descansa el dia previo.

### Si apruebas

1. Descarga o comparte tu badge digital.
2. Guarda el reporte.
3. Revisa beneficios AWS Certified.
4. Decide siguiente ruta:
   - Cloud Practitioner si quieres base cloud general.
   - Solutions Architect Associate si quieres arquitectura.
   - Machine Learning Engineer Associate si quieres seguir IA/ML.
   - Generative AI Developer Professional cuando tengas mas experiencia practica.

### Si no apruebas

1. Revisa reporte por dominios.
2. Haz una tabla de errores.
3. Estudia primero el dominio mas pesado fallado.
4. Repite ejercicios explicados.
5. Reagenda cuando vuelvas a 80-85% en simuladores.

## Mini plan de 5 dias antes de reservar

Dia 1:

- Revisar accommodations y modalidad.
- Hacer simulador completo.

Dia 2:

- Corregir errores.
- Repasar dominios 2 y 3.

Dia 3:

- Repasar dominios 4 y 5.
- Tarjetas de memoria.

Dia 4:

- Segundo simulador.
- Revisar servicios AWS por caso de uso.

Dia 5:

- Si el resultado es estable, reservar examen.
- Si no, extender estudio 3 a 5 dias mas.
